ES:
El siguiente proyecto funciona como un simulador de un portal de cine online.

Aparecerán el menú principal, los próximos estrenos, las películas en cartelera, y el contacto del cine.

Este es un sitio web estático, por lo que las películas no se actualizan en tiempo real. El proyecto está enfocado en la práctica del desarrollo frontend.



EN:
The following project works as a simulation of an online cinema portal.

The main menu, upcoming releases, movies currently in theaters, and the cinema's contact information will be displayed.

This is a static website, so the movies are not updated in real time. The project is focused on practicing frontend development.
