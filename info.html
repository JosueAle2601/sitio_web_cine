Sobre CineMax

Conoce el propósito y las características de nuestro sitio web.

NUESTRO SITIO

¿Qué es CineMax?

CineMax es un sitio web dedicado a presentar información sobre películas, próximos estrenos y producciones que actualmente se encuentran en cartelera.

El sitio permite consultar información básica de diferentes películas, incluyendo su título, género, duración, clasificación, fecha de estreno, director y sinopsis.

Además, los usuarios pueden consultar información relacionada con los precios de las entradas, alimentos, bebidas y diferentes combos disponibles.

NUESTRO PROPÓSITO

Una forma sencilla de descubrir el cine

El propósito de CineMax es reunir en un mismo lugar información que permita a los usuarios conocer las películas disponibles, descubrir próximos estrenos y consultar información útil antes de asistir al cine.

¿QUÉ PUEDES ENCONTRAR?

Información del sitio

CineMax está organizado en diferentes secciones para facilitar la navegación.

Próximos estrenos

Consulta películas que llegarán próximamente a las salas de cine y conoce sus fechas de estreno y sinopsis.

Cartelera

Explora las películas que actualmente se encuentran disponibles en cartelera.

Información de películas

Cada película cuenta con una página individual donde se presenta información más detallada sobre su producción.

Precios y combos

Consulta los precios de las entradas, alimentos, bebidas y combos disponibles, incluyendo las promociones especiales.

PROYECTO WEB

Características del proyecto

CineMax fue desarrollado como un proyecto web estático utilizando tecnologías fundamentales para la construcción de sitios web.

HTML5

Se utiliza para construir la estructura y el contenido de las diferentes páginas del sitio.

CSS

Se utiliza para definir el diseño, colores, distribución, animaciones, transiciones y adaptación a diferentes tamaños de pantalla.

Diseño responsive

El sitio adapta su distribución para facilitar su visualización en computadores, tabletas y dispositivos móviles.
